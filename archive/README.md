# Archive

This folder keeps experimental and personal project files recoverable without making
them part of the canonical workflow documented in the root README.

- `patrick_experiments/`: earlier training helpers, logs, and plotting scripts.
- `small_classif/`: smaller alternate classification prototype.
- `visualizer_experiment.py`: side-effectful gallery helper kept for reference.
- `visualize_cnn_copy.py`: copied visualization experiment.

Use the scripts in `Classification/` for the maintained workflow.
